## 🔧 Como rodar localmente

```bash
# Entre na pasta do frontend
cd Frontend

# Instale as dependências
npm install

# Entre na pasta do projeto e rode
cd .\GameStore\
npm run dev
```

O frontend estará disponível em: `http://localhost:3000`
